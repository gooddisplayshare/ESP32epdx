Operation Method:
1. Set up a WiFi hotspot on your phone, hotspot name: Goodisplay, hotspot password: 12345678
2. Install the WiFi-W1 mobile app software (Android system)
3. Use Arduino IDE to burn the firmware program onto the ESP32-L development board and maintain continuous power supply.
4. Open WiFi-W1, first select the current screen color, and then choose the corresponding screen size,
5. Click the WiFi Connect button. If the device is successfully connected, the software will display the data transfer progress and information above.
Note: The default IP number for the firmware is 208, and the mobile app needs to correspond to it.
(Default WiFi username: Goodisplay, password: 12345678)
